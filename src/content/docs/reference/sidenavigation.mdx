## Usage guidelines
### Use this component for:
<IconList>
    <IconListItem icon="check">
        **To display a navigational hierarchy with one to three levels.**
    </IconListItem>
    <IconListItem icon="check">
        **To display the “sub-navigation” within a section of the website.** 
    </IconListItem>
</IconList>

### Use something else for:
<IconList>
    <IconListItem icon="close">
        **Small site.** — If the site has fewer than five pages, consider organizing the page without a navigational hierarchy.
    </IconListItem>
    <IconListItem icon="close">
        **Existing navigation.** If your page already has a horizontal and vertical navigation bar, consider ways to simplify your navigation system.
    </IconListItem>
</IconList>

### Requirements for use:
<IconList>
    <IconListItem icon="report">
        **Show the current page.** Indicate where a user is within the navigational hierarchy. Use the “active” state to show users which page they have navigated to.
    </IconListItem>
    <IconListItem icon="report">
        **Always test your navigation.** If the navigation hierarchy is too long, users may miss items at the bottom. If it’s too deep, users may miss items that require too many clicks. Usability test to find the right balance between breadth and depth.
    </IconListItem>
</IconList>

## Accessibility guidance
Use the [USWDS side navigation accessibility tests](https://designsystem.digital.gov/components/side-navigation/accessibility-tests) to test button implementation.
- The width of the current menu item’s highlight border is set with the `$theme-sidenav-current-border-width` variable.
- The `.usa-sidenav` should be contained within a nav element so screen readers can indicate identify the component as a navigation section.
- If there are multiple `nav` landmarks on the page, the `nav` element must have an appropriate `aria-label` (e.g. "Side navigation") so screen readers can distinguish between different navigation sections.

## Code 

### Side navigation components
Grove provides a number of CSS classes that can be applied to various elements within the side navigation panel to help achieve a more standardized styling and layout.
| Name | Class | Description |
| ----------- | ----------- | ----------- |
| Side Navigation Item | `usa-sidenav__item` | Apply this class to a `<li>` element to designate an item within the side navigation panel. |
| Side Navigation Sublist | `usa-sidenav__sublist` | Apply this class to a `<ul>` element to designate a nested list of "child links" to be nested under a parent link within the sidenav. |
