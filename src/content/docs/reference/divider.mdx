## Using this component

The divider is available as a web component, a React component, and a CSS class. See [Using web components](/guides/webcomponents/) to set up npm, React, or the CDN first.

### Web component

```html
<grove-divider></grove-divider>
```

### React

```tsx
import { GroveDivider } from "@newjersey/njwds/react";

<GroveDivider />
```

### CSS class

Grove's stylesheet includes the same styles as a class, so a plain `<hr>` needs no JavaScript:

```html
<hr class="grove-divider" />
```

### Customization

The web component and the CSS class both support these CSS custom properties:

| Custom property | Default |
| ----------- | ----------- |
| `--grove-divider-color` | The theme's `base` color |
| `--grove-divider-margin-block` | `units(3)` on mobile, `units(6)` from the tablet breakpoint |
| `--grove-divider-margin-inline` | `units(2.5)` on mobile, `units(15)` from the tablet breakpoint |

Setting a margin property replaces the responsive default at every screen size.
