## Usage guidelines

### Use this component for
<IconList>
    <IconListItem icon="check">
        **Separating content into sections,** when spacing alone isn’t enough.
    </IconListItem>
    <IconListItem icon="check">
        **To group related content together.** The collection component can provide links to articles from a trusted source, popular guides and resources, or a collection of pages that cover different aspects of a single topic.
    </IconListItem>
</IconList>

### Use something else for for
<IconList>
    <IconListItem icon="close">
        **Separating individual items** The divider should not be used to separate individual items. Use spacing instead to distinguish between items.
    </IconListItem>
    <IconListItem icon="close">
        **Separating side-by-side content.** The divider is not meant for vertical use separating content next to each other. Use spacing instead or consider putting content into the card component.
    </IconListItem>
</IconList>

### Requirements for use
<IconList>
    <IconListItem icon="report">
        **Consistent spacing.** Ensure consistent padding and margin above and below dividers to avoid crowding.
    </IconListItem>
    <IconListItem icon="report">
        **Don't overuse dividers** within a page, which reduces scannability.
    </IconListItem>
</IconList>

## Using this component

The divider is available as a web component, a React component, and a CSS class. See [Using web components](/guides/webcomponents/) to set up npm, React, or the CDN first.

### Web component

```html
<grove-divider></grove-divider>
```

### React

```tsx
import { GroveDivider } from "@newjersey/njwds/react";

<GroveDivider />
```

### CSS class

Grove's stylesheet includes the same styles as a class, so a plain `<hr>` needs no JavaScript:

```html
<hr class="grove-divider" />
```

### Customization

The web component and the CSS class both support these CSS custom properties:

| Custom property | Default |
| ----------- | ----------- |
| `--grove-divider-color` | The theme's `base` color |
| `--grove-divider-margin-block` | `units(3)` on mobile, `units(6)` from the tablet breakpoint |
| `--grove-divider-margin-inline` | `units(2.5)` on mobile, `units(15)` from the tablet breakpoint |

Setting a margin property replaces the responsive default at every screen size.


## Accessibility guidance
### Decorative vs semantic dividers
Not all dividers should be announced to screen readers. Most dividers are decorative when used alongside headings or within well-structured content.

#### Use aria-hidden="true" for decorative dividers when:
- The divider only provides visual separation
- Content structure is already clear through headings or other markup

#### Do not use aria-hidden="true" for semantic dividers when:
- The divider marks a significant topic change meaningful to non-visual users
- The divider is the primary indicator of a content boundary
