## Usage guidelines

### Use this component for:
<IconList>
    <IconListItem icon="check">
        **NJIA-built websites and web apps.** Stand alone NJIA built websites and web apps can gather feedback using the feedback widget. Ex: UI Claim Status Portal, AI Assistant
    </IconListItem>
    <IconListItem icon="check">
        **NJ.gov sites where NJIA has embedded a tool.** Ex: Maternity timeline tool
    </IconListItem>
    <IconListItem icon="check">
        **OIT-built NJIA-designed information hubs** Ex: Disability Information hub
    </IconListItem>
</IconList>

### Use something else for:
<IconList>
    <IconListItem icon="close">
        **NJ.gov website of agencies we are not collaborating with.** Due to the nature of data storage within the feedback widget, it is not currently sustainable or recommended for NJ agencies to use the feedback widget without our collaboration.
    </IconListItem>
</IconList>

## User flow
1. **Rating:** At the bottom of a webpage, the widget asks user to rate their experience of the page with "Yes" and "No" buttons. Upon clicking an option, the rating is saved to a Google Sheet and/or Google Analytics* (along with page URL, and submission datetime).
1. **Comment:** (Optional) Widget asks user to optionally share feedback in a free text field. Upon submitting, this text is recorded to Google Sheets.
1. **Email:** (Optional) Widget asks user to optionally share their email to join a user testing group. Upon submitting, this email is recorded to Google Sheets.

## Known issues
- **Not dismissible:** Allowing the feedback widget to be dismissible is a requested feature on our backlog. 
- **Text customizations:** Overriding the default text strings in the feedback widget (separate from the `contact-link` attribute) requires JavaScript
