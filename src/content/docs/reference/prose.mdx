## Usage Guidelines

### Use this component for:
<IconList>
    <IconListItem icon="check">
        **Long form content on websites** the `prose` attribute automatically applies Grove type styles to headings and body text.
    </IconListItem>
</IconList>

### Use something else for:
<IconList>
    <IconListItem icon="close">
        **Content within components.** Any content within components will not need the `prose` attribute to be applied.
    </IconListItem>
</IconList>
