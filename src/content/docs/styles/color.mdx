## Theme colors
Theme color tokens determine Grove’s key color families such as primary and base. Each theme token is drawn from a [USWDS system color token](https://designsystem.digital.gov/design-tokens/color/system-tokens/) and only token-based colors are used in official components.

**Base** is Grove’s neutral color, used in the text color throughout, as well as most surfaces, such as backgrounds, borders, and cards.

**Primary**, **secondary**, and **accent colors** can be thought of as falling into a proportional 60/30/10 relationship: about 60% of your site’s color would be the primary color family, about 30% would be the secondary color family, and about 10% would be the accent color families (accent-warm and accent-cool). Note that these proportions are for non-base colors. In many cases, the neutral base text color will be the predominant tone on your site.

Each color family usually has seven possible lightness grades, from lightest to darkest.

## State colors
State color tokens are designed to be useful and effective for that has states or alerts. Each state token is drawn from a [USWDS system color token](https://designsystem.digital.gov/design-tokens/color/system-tokens/) and and only token-based colors are used in official components.

The state color palette is divided into five high-level role-based color families: info, error, warning, success, and emergency.

Each state color family generally has five possible lightness grades, from lighter to darker.

**Note:** Grove does not utilize the disabled color family as we recommend against the use of disabled states in components.
