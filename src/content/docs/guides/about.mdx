**Grove** is the design system for the State of New Jersey. Built on top of USWDS (US Web Design System), it provides components and guidance that are specific to the needs of New Jersey, while also deprecating or excluding patterns that are not accessible or user friendly. Accessibility is built into Grove, and our documentation provides additional guidance on how best to use each component.

## Why use Grove?

Grove enables you to deliver consistent and accessible products for the residents of New Jersey. This makes sure all residents can use our products while also building trust. The design system should also make work as a designer or engineer simpler, since you can refer to one source of truth for common components. Designs and code are aligned to minimize confusion that can arise when handing off mocks to engineers.

## Benefits

- **For residents:** Consistent experiences that build trust in State services
- **For agencies:** Confidence that accessibility requirements are met
- **For designers:** Rapid prototyping with pre-built components and variants
- **For engineers:** Pre-tested, accessible components that are ready-to-use

## Accessibility standards

In Grove, according to [ADA requirements for state government](https://www.ada.gov/resources/2024-03-08-web-rule/), we hold ourselves to a WCAG 2.1 AA level.
- We benefit from the [accessibility testing](https://designsystem.digital.gov/documentation/accessibility/) that USWDS has done on the components we consume.
- In addition to this, we customize components with accessibility best practices as they come up through testing. 
- Teams also need be sure to do manual and automated accessibility testing on implementations of the design system to catch accessibility issues.
