## Grove roadmap

### What's coming up soon?

* Prioritizing accessibility issues/debt; making sure Grove components work as expected for all users
* Storybook and Figma alignment; making sure designers and engineers have a clear starting point for the components available in Grove (NJWDS).

### What comes after that?
  
* More Grove component enhancements
* Web component research and experiments

### What are some long term goals?

* Web components; we want to reduce the need to rebuild Grove components in different environments (like react and bootstrap, for instance)
* More templates & component iteration; adding to Grove based on common needs that are encountered by NJIA product teams
