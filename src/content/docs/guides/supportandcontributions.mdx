## Grove roadmap

### What's coming up soon?

- Storybook and Figma alignment; making sure designers and engineers have a clear starting point for
  the components available in Grove (NJWDS).
- Baselines for current design system usage; measuring how Grove is used today to help inform future
  roadmap priorities.

### What comes after that?

- Documentation site; this site is currently a work-in-progress to showcase Grove components and
  guidance.
- Feedback loops; we want there to be clear places for feedback from feature requests to support
  questions (more below).

### What are some long term goals?

- Web components; we want to reduce the need to rebuild Grove components in different environments
  (like react and bootstrap, for instance)
- More templates & component iteration; adding to Grove based on common needs that are encountered
  by NJIA prodcut teams
