Use language that works regardless of how a user accesses the content: screen, screen reader, phone,
or other device.

## Interaction language

Use "select" instead of "click," "tap," or "press." These terms assume a specific device.

| ✅ Do         | ❌ Don’t                |
| ------------- | ----------------------- |
| Select submit | Click the submit button |
|               | Tap submit              |
|               | Press submit            |

## Sensory language

Avoid "view," "see," "hear," and "listen" – they assume a specific ability or device. Use
intent-based language instead.

| ✅ Do                      | ❌ Don’t                  |
| -------------------------- | ------------------------- |
| Go to your medical records | View your medical records |
| Review your lab results    | See your lab results      |
| Check your claim status    |                           |

## Directional language

Avoid references to screen position – layout shifts across devices and screen sizes.

| ✅ Do                              | ❌ Don’t                                              |
| ---------------------------------- | ----------------------------------------------------- |
| Select the link from the main menu | Select the link on the top right corner of the screen |

## Color references

Do not use color to give instructions because it may confuse users who have colorblindness.

| ✅ Do         | ❌ Don’t                      |
| ------------- | ----------------------------- |
| Select submit | Select the blue Submit button |
