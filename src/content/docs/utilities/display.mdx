### Pin 
The `pin` utilities position an item absolutely to the specified side.

| Name | Value |
| ----------- | ----------- |
| `.pin-top` | top: 0 |
| `.pin-bottom` | bottom: 0 |
| `.pin-left` | left: 0 |
| `.pin-right` | right: 0 |
| `.pin-x` | left: 0; right: 0 |
| `.pin-y` | top: 0; bottom: 0 |
| `.pin-all` | top: 0; right: 0; bottom: 0; left: 0 |
| `.pin-none` | top: auto; right: auto; bottom: auto; left: auto |

## Advanced settings

### Responsive variants

Add a responsive breakpoint prefix separated with a `:` to target a utility at a responsive breakpoint and higher, following a mobile-first methodology.

**Example**

`.tablet:display-none`

**Output**

```scss
@media screen and (min-width: 640px) {
  .tablet\:display-none {
    display: none;
  }
}
```
