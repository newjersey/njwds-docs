## Advanced settings 

### State variants 
Use a state prefix separated with a `:` to target a utility in a specific state.

**Example:** 
`.hover:bg-primary-vivid` 

**Output:** 
`.hover\:bg-primary-vivid:hover { background-color: #0052de; }`
