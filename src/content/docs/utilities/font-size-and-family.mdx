## Basic settings 

### Font size
CSS Property: `font-size`

Sets the font size and font family together. The first part of the class name picks the font, either by type (`mono`, `sans`, `serif`) or by role (`body`, `heading`, `ui`, `code`, `alt`). The second part picks the size, from `3xs` to `3xl`. Each typeface's sizes are adjusted so text looks about the same size across fonts. Sizes are set in `rem`, so they grow when someone increases their browser's default text size.

### Font family 
CSS Property: `font-family` 

Sets only the typeface, without changing the font size. Type-based classes name the kind of font. Role-based classes name how the text is used, so text keeps the right font if the design system changes the typeface for that role. Each font family includes system fallback fonts in case the web font doesn't load.

## Advanced settings
### Responsive variants
Add a responsive breakpoint prefix separated with a `:` to target a utility at a responsive breakpoint and higher, following a mobile-first methodology.

**Example**
`.tablet:font-body-lg`

#### Output

```css
@media screen and (min-width: 640px) {
  .tablet\:font-body-lg {
    font-size: 1.25rem;
  }
}
```
